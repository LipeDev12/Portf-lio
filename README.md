# 🚀 Portfólio de Projetos - HTML & CSS

> Projeto prático desenvolvido no **SENAI**, sob orientação do **Professor Denani**, com o objetivo de consolidar e apresentar a aplicação dos conceitos fundamentais de HTML5 e CSS3.

---

## 📌 Sobre o Projeto

Este portfólio centraliza os projetos desenvolvidos ao longo do curso. Ele funciona como uma vitrine virtual para demonstrar o aprendizado prático no desenvolvimento *front-end*, reunindo estruturação de código, design visual e boas práticas de desenvolvimento web.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de páginas e organização de conteúdo.
* **CSS3:** Estilização visual, layouts flexíveis, regras de tipografia e efeitos de transição.
* **Git & GitHub:** Controle de versão do código e disponibilização do projeto online.

---

## 💡 Conceitos Aplicados

* **HTML Semântico:** Utilização correta de elementos como `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>` para melhor acessibilidade e SEO.
* **CSS Flexbox & CSS Grid:** Criação de *layouts* dinâmicos, alinhamento de componentes e galerias de projetos.
* **Design Responsivo:** Adaptação da interface para diferentes tamanhos de tela (desktop, tablet e mobile) por meio de *Media Queries*.
* **Estilização e Usabilidade:** Padronização de esquemas de cores (variáveis CSS), tipografia adequada, espaçamentos consistentes e estados interativos (como `:hover` e `:focus`).
